## Сценарий видео (3–4 минуты)

1. Показать, что APK установлен «с нуля», и открыть приложение с включённым интернетом.
2. Нажать «Скачать» в карточке моделей, показать прогресс до конца.
3. Включить режим «в самолёте» и показать это в шторке.
4. Импортировать запись («Из файла»), выбрать «Определить» число участников, запустить.
5. Показать прогресс по этапам (определение говорящих, распознавание, правка текста, выжимка).
6. Открыть расшифровку: участники, реплики с метками времени, «Главное», заголовок с RTF.
7. «Экспорт» → «Сохранить в файл» → «JSON расшифровки», открыть файл и показать поля
   `speaker_id`, `start_ms`, `end_ms`, `text`.
8. Показать, что при выключенной сети ничего не потерялось и не запрашивается.
