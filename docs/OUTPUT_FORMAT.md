# Формат результата

Приложение сохраняет и отдаёт расшифровку в двух JSON-форматах. Оба выбираются в меню
«Экспорт» на экране расшифровки, каждый можно отправить или сохранить в файл.

## «JSON расшифровки (.json)» — формат задания

Объект с одним ключом `transcript`: массив реплик в порядке времени. Других ключей нет.

```json
{
  "transcript": [
    {
      "speaker_id": "speaker_1",
      "start_ms": 1250,
      "end_ms": 4380,
      "text": "Добрый день!"
    }
  ]
}
```

| Поле | Тип | Значение |
|---|---|---|
| `speaker_id` | строка | `speaker_N`, где N — номер участника с единицы в порядке первого появления. Переименование участника в приложении идентификатор не меняет |
| `start_ms`, `end_ms` | целое | Начало и конец реплики в миллисекундах от начала записи; `end_ms` не меньше `start_ms` |
| `text` | строка | Текст реплики. Если текст исправила языковая модель, здесь исправленный |

Каждая фраза — отдельная запись. Файл в кодировке UTF-8 без BOM, кириллица записана как есть.
Пустая расшифровка даёт `{"transcript": []}`.

## «Расширенный JSON (.json)»

Подробный документ для людей и своих скриптов: название, дата, длительность, время обработки и
RTF, источник, модель распознавания, языковая модель (если она исправляла текст), язык, отметки
при записи, участники с именами и реплики. У реплики, которую исправила языковая модель, есть
`rawText` — текст, как его распознала модель речи.

Файл называется `<название>-extended.json`, чтобы его не путали с форматом задания.
